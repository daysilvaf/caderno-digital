# Caderno Digital · Química dos Produtos Naturais

Caderno digital no estilo Noteful, feito em React + TypeScript + Vite.

## Rodar no computador

```bash
npm install
npm run dev
```

Abra o endereço que aparecer (normalmente http://localhost:5173).
